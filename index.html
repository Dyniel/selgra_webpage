Microgravity projects, by students – for students

This page is a proof-of-concept for a student microgravity community portal. Guests can see what is happening; members, after entering a simple password, unlock sign-ups, internal resources and a personalised view – all implemented client-side and hostable on GitHub Pages.

3× ESA-style student projects in the pipeline (parabolic flight, drop tower, CubeSat).
10+ partner labs and supervisors supporting student microgravity research.
Open to any motivated student – engineering, life sciences, medicine, physics.

What this PoC demonstrates

  • Guest vs member view, with a simple password gate (no backend).
  • Event list where guests see content but cannot register.
  • Local-only profile and registrations stored in the browser.
  • Compatibility with static hosting (e.g. GitHub Pages).

Typical student microgravity journey

Discover opportunities → Join open calls → Form a team → Co-design experiment with a supervisor → Apply to ESA-style programmes → Execute hardware tests and campaigns → Share results with the community.

    About the community

    This portal concept is built around a simple idea: students should have a clear entry point to microgravity research opportunities, and a protected space where active members can coordinate real projects with supervisors and partner institutions.

    The structure shown here is intentionally minimal: it is meant to be clonable, hostable on GitHub Pages and extendable with proper authentication, databases and dashboards when needed.

    Background and context

    Student microgravity projects have historically grown around isolated teams and one-off calls. A dedicated student community portal makes it easier to:

    • Archive knowledge from past campaigns and experiments.
    • Onboard new students with clear paths towards concrete projects.
    • Expose local initiatives to an international network of mentors and partners.

    How students would typically join

    In a full deployment, this section would contain direct application forms, eligibility criteria and information on how to combine studies with project work. In this PoC it simply marks where that content would live and how it would look in the overall layout.

    Example pipeline: short motivation form → informal interview with senior students → assignment to a project group → access to internal resources → hands-on work on an experiment.
